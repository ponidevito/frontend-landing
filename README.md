# Modern Frontend Landing

Modern responsive landing page built with HTML, SCSS and JavaScript.  
The project showcases responsive layouts, reusable UI components, animations and interactive frontend elements.

## Live Demo

Demo https://ponidevito.github.io/ok-landing/

---

## Preview

This project was created as a frontend portfolio showcase focused on:

- Responsive Design
- Modern UI Layouts
- SCSS Architecture
- JavaScript Interactions
- Reusable Components
- Adaptive Mobile Experience

---

## Technologies Used

- HTML5
- SCSS
- JavaScript (ES6)
- Swiper.js
- Gulp

---

## Features

- Responsive layout across all devices
- Interactive sliders and UI components
- Animated modal windows
- Dynamic content sections
- Clean and structured codebase
- Modern visual design
- Portfolio-oriented architecture
